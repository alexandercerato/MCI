05 — METHODOLOGY v0.1

Built like a benchmark, not a headline.

The design follows the Baltic principle: define a standard transport product, select representative observable routes, assess those routes consistently, then combine them into a transparent basket.

01

Reference shipment

1 × 40' dry/HC container, general cargo, terminal-to-terminal, westbound, quoted in USD/FEU. Customs duties, VAT, cargo insurance, detention/demurrage and bespoke last-mile services are excluded unless a source makes them inseparable.

02

Reference lanes

MC1 Xi’an–Alat 40%, MC2 Xi’an–Tbilisi 30%, MC3 Xi’an–Türkiye 30%. These weights are provisional and will be reviewed when a deeper recurring quote set is available.

03

Fixing discipline

The site checks sources daily. It does not interpolate prices between published observations. No new market observation means no new fixing.

04

Fail safe

If scraping fails or a source changes layout, the bot keeps the previous verified value instead of replacing it with zero or an inferred number.
