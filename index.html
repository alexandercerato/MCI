07 — METHODOLOGY v0.3

A benchmark, not a made-up daily price.

The automation checks for new market evidence every 12 hours. A new MCI fixing is created only when a verified reference-lane observation changes the weighted basket.

01

Reference shipment

1 × 40' dry/HC container, general cargo, terminal-to-terminal, westbound, quoted in USD/FEU. Duties, VAT, cargo insurance, detention/demurrage and bespoke last-mile services are excluded where separable.

02

Reference lanes

MC1 Xi’an–Alat 40%, MC2 Xi’an–Tbilisi 30%, MC3 Xi’an–Türkiye 30%. Weights remain provisional pending a deeper recurring quote set.

03

January 2026 base

Jan 2026 = 100 uses a provisional $6,000/FEU base assessment, the midpoint of a public early-2026 $5,000–$7,000 range. From June onward the headline fixing uses the three-lane basket.

04

12-hour source checks

GitHub Actions runs at 05:17 and 17:17 UTC. If no new verified quote exists, the previous fixing is retained. The dashboard never fabricates a daily move by interpolation.
